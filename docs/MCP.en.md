# GenImage MCP Server

[繁體中文](MCP.md) | English | [日本語](MCP.ja.md) | [한국어](MCP.ko.md)

GenImage exposes the same MCP tool core through two JSON-RPC 2.0 transports using protocol version `2025-06-18`: a standalone stdio server and a localhost HTTP API controlled by a switch in GenMedia.app.

## Standalone stdio

```bash
./build.command
MCP_BIN_DIR="$(swift build -c release --show-bin-path)"
"$MCP_BIN_DIR/GenImageMCP"
```

For production integration, use the absolute path generated by `build.command`. Running `swift build` alone does not copy the metallib.

Run `swift build -c release --show-bin-path` to obtain the release directory used by the current toolchain. Do not hard-code the legacy SwiftPM `.build/arm64-apple-macosx/release` path.

The stdio server owns its `InferenceServices` and runs inference inside the `GenImageMCP` process. GenMedia.app does not need to be running.

## App HTTP API

Enable Settings → MCP Integration in GenMedia.app to expose:

```text
http://127.0.0.1:12181/mcp
```

This endpoint binds to localhost only and accepts JSON-RPC over HTTP `POST`; turning the switch off stops the listener immediately. The HTTP transport calls the same `MCPServer` tool core as stdio. It does not start a stdio child process and is not a proxy to another service. Because this mode is embedded in the app, GenMedia.app must remain open; use the standalone stdio executable for headless integrations.

## MCP Methods

- `initialize`
- `notifications/initialized`
- `ping`
- `tools/list`
- `tools/call`

Each stdio message is one UTF-8 JSON-RPC object per line. stdout contains protocol messages only; diagnostics must be written to stderr.

## Tools

- `genimage_models_list`
- `genimage_profiles_list`
- `genimage_upscale_image`
- `genimage_generate_image`
- `genimage_edit_image`
- `genimage_describe_image`
- `genimage_generate_subtitle`

Text-to-image, image editing, image description, and optional subtitle translation use native MLX Swift runtimes. Subtitle recognition uses native Core ML runtimes. `mlx.metallib` must be located beside the release executable, which `build.command` handles automatically.

The model root can be set through `model_root` or `GENIMAGE_MODEL_ROOT`.

### `genimage_generate_subtitle`

Required arguments are the absolute source `input_path`, ASR `model_path`, and `model_id`. Supported ASR model IDs are:

- `argmaxinc/whisperkit-coreml@large-v3-turbo`: multilingual Whisper
- `FluidInference/paraformer-large-zh-coreml`: Chinese Paraformer
- `FluidInference/parakeet-0.6b-ja-coreml`: Japanese Parakeet

`format` accepts `srt` or `vtt` and defaults to `srt`. `language_code` selects the source language or `auto`. `output_path` may name a non-existing absolute path with the matching extension. When `target_language_code` is present, `translation_model_path` and `translation_model_id` are also required; a local Qwen text model translates to `zh-Hant`, `zh-Hans`, `en`, `ja`, or `ko` while preserving the source timeline.

The tool creates `SubtitleGenerationRouter` and its inference services directly inside the `GenImageMCP` process. It neither connects to GenMedia.app nor requires the app to be running.

## Configuration Example

Using a compiled executable avoids working-directory differences between MCP clients:

```json
{
  "mcpServers": {
    "genimage": {
      "command": "/absolute/path/to/GenImageMCP",
      "env": {
        "GENIMAGE_MODEL_ROOT": "/absolute/path/to/models"
      }
    }
  }
}
```

MCP clients should use the release executable generated by `build.command` to ensure that the MLX runtime and executable are in the same directory.

## Verified Behavior

- Smoke tests pass for `initialize` and a seven-tool `tools/list` response.
- The app HTTP transport responds to `tools/list` on localhost with the same seven tools as stdio.
- Unknown methods return JSON-RPC `-32601`.
- `genimage_generate_image` completed an end-to-end 256×256, one-step generation with a local Z-Image Turbo Q4 model.
- `genimage_describe_image` completed a Traditional Chinese image description with a local Qwen3-VL 4-bit model.
- `genimage_upscale_image` completed 4× upscaling with a local Real-ESRGAN Core ML model.
- Internal model loggers do not write to stdout, keeping stdio as pure JSON-RPC.
