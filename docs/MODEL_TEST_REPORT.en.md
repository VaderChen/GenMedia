## Text to Image

Model: `z-image-turbo-q4`

- Size: approximately 7.8 GB.
- Complete Diffusers `ZImagePipeline` directory structure.
- Transformer and text encoder use 4-bit affine quantization with group size 32.
- Successfully loaded `Z-Image.swift` commit `28bfcf3148c041a554629247170eb54d9ac46830`.
- Successful 256×256, one-step, seed 1 test.
- Produced a 256×256 RGBA PNG.
- Model loading, prompt encoding, denoising, VAE decoding, and file writing all completed.
- MCP `genimage_generate_image` passed an end-to-end 256×256, one-step, seed 7 test with an 8-bit RGBA PNG output.
- The app's `ZImageTextToImageService` directly wraps the native `ZImagePipeline` and no longer invokes an external CLI.

SwiftPM execution requires `mlx.metallib`. A compatible file is stored in `RuntimeSupport`, and `build.command` copies it beside the release executable so the app does not depend on another application at runtime.

## MCP Validation

The standard JSON-RPC 2.0 stdio MCP server completed the following smoke and end-to-end tests:

- `initialize` returns protocol version `2025-06-18`.
- `tools/list` lists seven tools for models, profiles, upscaling, text-to-image, image editing, image-to-text, and subtitle generation.
- `genimage_generate_image` directly invokes the native Z-Image runtime and verifies the output PNG dimensions and format.
- `genimage_describe_image` directly invokes the native Qwen3-VL runtime and outputs a Traditional Chinese description.
