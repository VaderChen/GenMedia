# 開発ロードマップ

[繁體中文](ROADMAP.md) | [English](ROADMAP.en.md) | 日本語 | [한국어](ROADMAP.ko.md)

## 完了：コア機能

- Swift Package、macOS 14 以降の App、Apple Silicon ネイティブ MLX／Core ML 推論、ハイブリッド Web UI。
- テキストから画像、画像からテキスト、画像から画像、テキストから動画、画像から動画、テキストから音楽、4 倍アップスケールの独立サービスとアセット lineage。
- Z-Image Turbo、Qwen3-VL、Qwen 2511、LTX-2.3、ACE-Step 1.5、MiniMax Music 3、Real-ESRGAN のプロファイル。
- 音楽 Prompt、任意の歌詞、一般的な音楽スタイル、5～300 秒設定、MP3／M4A／AAC／FLAC 出力。
- モデルセンターのダウンロード、一時停止、再開、ディスク事前確認、修復、削除、プロファイル依存関係確認、インストール後の自動並べ替え。
- ジョブキュー、キャンセル、進捗、残り時間推定、生成時間、モデルキャッシュ、手動メモリ解放。
- 各ワークスペースタブを永続化された生成プロジェクトとして扱い、再起動後にアセット、操作、選択状態、プロファイルスナップショットを復元。
- 作成パネルの部分描画、カーソルと IME の保護、音声／動画の連続再生。
- `Image-YYYYMMDD-HHmm`、`Video-YYYYMMDD-HHmm`、`Music-YYYYMMDD-HHmm` の出力名と同一分の重複防止連番。
- Release App bundle、MLX metallib、ネイティブ MCP 推論ツール、独立した DMG 署名／公証フロー。

## 現在の段階：安定化と検証

1. 16 GB、24 GB、32 GB 環境で ACE-Step 長時間音声のメモリ、熱負荷、キャンセル、復元テストを完了します。
2. ダウンロード中断、ハッシュ不一致、ディスク不足、再起動復元のテスト範囲を拡張します。
3. アプリ異常終了、アセット欠落、索引修復時の複数タブプロジェクト整合性を検証します。
4. Runtime、モデル、LoRA のライセンス画面と配布 manifest を完成させます。
